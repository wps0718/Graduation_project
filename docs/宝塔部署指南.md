## 1. 登录宝塔面板 & 安装软件

### 1.1 登录宝塔

打开浏览器，访问 `http://8.163.37.68:8888/`（注意端口可能不是 8888，以你安装时为准）

> 如果不知道宝塔地址和账号，在服务器终端执行 `bt` 命令查看。

### 1.2 安装所需软件

进入宝塔 **软件商店**，搜索并安装以下软件：

| 软件 | 版本要求 | 用途 |
|------|---------|------|
| **Nginx** | 1.22+ | Web服务器 / 反向代理 |
| **MySQL** | 8.0+ | 数据库 |
| **Redis** | 7.x | 缓存 / 分布式锁 |
| **Node.js** | 18.x+ | 构建前端（如果需要在服务器构建） |

宝塔内操作路径：**软件商店 → 应用搜索 → 一键安装**

### 1.3 安装 Java 17

宝塔软件商店默认没有 Java，需要手动安装。在宝塔 **终端** 执行：

```bash
# 方式1：使用 bt 的 Java 一键（如果宝塔商店有）
# 在软件商店搜索 "Java" 并安装

# 方式2：手动安装（推荐）
wget https://download.oracle.com/java/17/latest/jdk-17_linux-x64_bin.tar.gz -O /tmp/jdk17.tar.gz
mkdir -p /usr/local/java
tar -xzf /tmp/jdk17.tar.gz -C /usr/local/java/
JDK_DIR=$(ls /usr/local/java/)
echo "export JAVA_HOME=/usr/local/java/$JDK_DIR" >> /etc/profile
echo "export PATH=\$JAVA_HOME/bin:\$PATH" >> /etc/profile
source /etc/profile
java -version
```

> **验证**：执行 `java -version` 应显示 `openjdk version "17.x.x"`

### 1.4 安装 Supervisor（进程守护）

在宝塔 **软件商店** 搜索 **"进程守护管理器"** 并安装。

> 用于保证 Spring Boot 后端一直在运行，崩溃时自动重启。

## 3. 创建数据库

### 3.1 创建数据库和用户

在宝塔 **数据库** 页面：

1. 点击 **添加数据库**
2. **数据库名**: `secondhand`
3. **用户名**: `secondhand`（或自定义）

5. **访问权限**: `localhost`（仅本机）

### 3.2 导入 SQL 初始化脚本

**方式 A：通过宝塔面板导入（推荐）**

1. 在宝塔 **文件** 页面，进入 `/root/` 目录

4. 点击 `secondhand` 数据库右侧的 **导入**

6. 点击 **导入**

**方式 B：通过终端导入**

```bash
# 先在本地电脑把 init.sql 上传到服务器（本机 Windows 终端执行）

# 然后在宝塔终端执行

```

## 4. 部署后端 Java 项目

### 4.1 在服务器上准备代码

**方式 A：从 GitHub 拉取（推荐，后续更新方便）**

在宝塔 **终端** 执行：

```bash
cd /opt
git clone https://github.com/wps0718/Graduation_project.git secondhand
cd secondhand
```

**方式 B：本地打包上传**

```bash
# 本机 Windows 终端执行
cd "G:\Code\Graduation_project"
mvn clean package -DskipTests

# 上传 jar 包和配置
scp target/*.jar root@8.163.37.68:/data/secondhand/app.jar
```

### 4.2 创建生产配置文件

在宝塔 **文件** 页面：

1. 进入 `/opt/secondhand/src/main/resources/`（如果 git clone）
2. 或者创建 `/data/secondhand/` 目录
3. 新建文件 `application-prod.yml`，内容如下：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/secondhand?useSSL=true&serverTimezone=Asia/Shanghai&characterEncoding=utf8&useUnicode=true&connectionCollation=utf8mb4_bin
    username: secondhand
    password: ${DB_PASSWORD}
    driver-class-name: com.mysql.cj.jdbc.Driver
  data:
    redis:
      host: localhost
      port: 6379
      database: 0

server:
  port: 3576

jwt:
  secret: ${JWT_SECRET}
  expiration: 86400000
  admin-expiration: 86400000

upload:
  path: /data/secondhand/uploads/
  url-prefix: /uploads/

wx:
  appId: ${WX_APP_ID}
  appSecret: ${WX_APP_SECRET}

pickup:
  aes-key: ${PICKUP_AES_KEY}

mybatis-plus:
  configuration:
    log-impl: org.apache.ibatis.logging.slf4j.Slf4jImpl
```

### 4.3 创建目录

在宝塔 **终端** 执行：

```bash
mkdir -p /data/secondhand/uploads
mkdir -p /data/secondhand/logs
```

### 4.4 通过 Supervisor 启动后端

在宝塔 **软件商店 → 进程守护管理器**（或者左边栏有 **Supervisor** 入口）：

1. 点击 **添加守护进程**
2. **名称**: `secondhand`
3. **启动用户**: `root`
4. **运行目录**: `/opt/secondhand`（git clone 目录）
5. **启动命令**:

```bash
java -jar /opt/secondhand/target/secondhand-0.0.1-SNAPSHOT.jar \
  --spring.profiles.active=prod \
  --spring.config.additional-location=/opt/secondhand/src/main/resources/application-prod.yml
```

> 注意：jar 文件名可能不同，请 `ls /opt/secondhand/target/*.jar` 确认实际文件名

6. **环境变量**（点击"添加环境变量"按钮逐个添加）：

| 变量名 | 值 | 说明 |
|--------|------|------|
| `DB_PASSWORD` | 你的数据库密码 | 第 3.1 步设置的 |
| `JWT_SECRET` | `（随机生成）` | 见下方生成说明 |
| `WX_APP_ID` | `wx39b09d716cef8023` | 你的微信 AppId |
| `WX_APP_SECRET` | `（新的AppSecret）` | ⚠️ 去微信平台重置后的值 |
| `PICKUP_AES_KEY` | `（随机生成）` | 16位随机字符串 |
| `UPLOAD_PATH` | `/data/secondhand/uploads/` | 上传目录 |

> **生成 JWT_SECRET 的命令**（在宝塔终端执行）：
> ```bash
> openssl rand -hex 32
> ```
> 复制输出结果作为 JWT_SECRET 的值

> **生成 PICKUP_AES_KEY 的命令**：
> ```bash
> openssl rand -hex 16
> ```

7. 点击 **提交**

### 4.5 检查后端是否启动成功

在宝塔 **终端** 执行：

```bash

# 或者在 Supervisor 页面看状态是否显示 "运行中"

# 测试 API

# 查看日志
```

## 6. 配置 Nginx 反向代理

这一步是关键：管理后台的 API 请求需要转发到 Java 后端，同时小程序也需要访问 API。

### 6.1 先添加 API 站点

在宝塔 **网站** 页面，再添加一个站点：

1. 点击 **添加站点**
2. **域名**: `api.gdqysecondhand.xyz`
3. **根目录**: 随便填一个（比如 `/data/secondhand/api-temp`）
4. **PHP版本**: **纯静态**
5. 提交

### 6.2 修改管理后台站点的 Nginx 配置

在宝塔 **网站** 页面：

1. 找到 `gdqysecondhand.xyz` 站点，点击右侧 **设置**
2. 选择 **配置文件** 标签
3. 将内容替换为：

```nginx
server {
    listen 80;
    server_name gdqysecondhand.xyz;
    
    # 管理后台静态文件
    root /data/secondhand/admin/dist;
    index index.html;

    # API 反向代理（/admin/ 开头的请求转发到后端）
    location /admin/ {
        proxy_pass http://127.0.0.1:3576;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 小程序 MINI API
    location /mini/ {
        proxy_pass http://127.0.0.1:3576;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 图片等静态资源
    location /uploads/ {
        alias /data/secondhand/uploads/;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # 前端 SPA 路由（所有非文件请求返回 index.html）
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 大文件上传
    client_max_body_size 50M;
}
```

4. 点击 **保存**

### 6.3 修改 API 站点的 Nginx 配置

同样方式，找到 `api.gdqysecondhand.xyz` 站点 → **设置** → **配置文件**：

```nginx
server {
    listen 80;
    server_name api.gdqysecondhand.xyz;

    # 所有请求转发到 Java 后端
    location / {
        proxy_pass http://127.0.0.1:3576;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # WebSocket 聊天连接
    location /ws/ {
        proxy_pass http://127.0.0.1:3576/ws/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 文件上传
    location /uploads/ {
        alias /data/secondhand/uploads/;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    client_max_body_size 50M;
}
```

### 6.4 重载 Nginx 使配置生效

在宝塔 **网站** 页面，点击 **Nginx 服务** 右侧的 **重载配置** 按钮。

或者在终端执行：

```bash

```

## 7. 申请 SSL 证书（HTTPS）

### ⚠️ 重要前提
**小程序强制要求 HTTPS**，所以必须配置 SSL 证书。

### 7.1 宝塔一键申请（推荐）

宝塔提供免费的 Let's Encrypt SSL 证书，操作很简单：

1. 宝塔 **网站** 页面
2. 找到 `gdqysecondhand.xyz`，点击右侧 **设置**
3. 选择 **SSL** 标签
4. 选择 **Let's Encrypt** 页签
5. **勾选域名**: 确保 `gdqysecondhand.xyz` 被勾选
6. 点击 **申请**（会验证域名所有权）
7. 申请成功后，开启 **强制 HTTPS**

同样为 `api.gdqysecondhand.xyz` 重复上述操作。

### 7.2 申请成功后自动配置

宝塔会自动修改 Nginx 配置加入 HTTPS 监听。申请成功后，配置会变成这样（宝塔自动生成，一般无需手动修改）：

```nginx
# 自动生成的 80→443 重定向
server {
    listen 80;
    server_name gdqysecondhand.xyz;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name gdqysecondhand.xyz;

    ssl_certificate /www/server/panel/vhost/cert/gdqysecondhand.xyz/fullchain.pem;
    ssl_certificate_key /www/server/panel/vhost/cert/gdqysecondhand.xyz/privkey.pem;

    # ... 其余配置和第6.2步一样 ...
}
```

> ✅ 宝塔会自动续期证书（每个月），无需你操心。
